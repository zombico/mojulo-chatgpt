# Optional Dot orientation

Dots add ongoing coordination when available. They are not required for Mojulo artifacts or source work. Without a dot, use [Getting started](../docs/GETTING-STARTED.md) directly in Work or Codex.

Read [Shared orientation](../docs/ORIENTATION.md) first, then [Capabilities](CAPABILITIES.md), [Execution routing](EXECUTION-ROUTING.md), and [Examples](EXAMPLES.md).

Keep concise notes about goals, decisions, issues, artifacts, and next tasks. Notes supplement actual recipes/checkpoints; they are not scene state. Execute with available tools or create a Work/Codex task when supported and authorized. Never make a Dot handoff a prerequisite for an available direct executor.

These documents are portable instructions, not automatically installed platform configuration. Check actual account and tool access. See [Meet dots](https://learn.chatgpt.com/docs/dots) and [Tasks and memory](https://learn.chatgpt.com/docs/dots/tasks-and-memory) for current platform behavior.
