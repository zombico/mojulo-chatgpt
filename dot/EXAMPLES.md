# Example requests

## Create and iterate

“Build an underwater city, then make its terrain more organic.”

Use runtime orientation and scene operations in an available execution environment. Retain the ref and portable recipe. For the follow-up, inspect state, discover terrain/waveform schemas, patch the same ref, and return updated exports. Record pending visual checks.

## Continue elsewhere

“Continue that city in a new Work task.”

Locate current portable state and exact build. Transfer files, restore in the new workspace, and verify the ref before editing. If state is missing, report what must be recovered; do not reconstruct silently from prose.

## Fix core source

“Waveform terrain changes disappear on export. Fix Mojulo.”

Target `zombico/mojulo` with the failing recipe, version, commands, expected/observed behavior, and validation. Use [HANDOFF.md](../codex/HANDOFF.md). Report task-creation or access limitations.

## Fix the integration

“The Work bootstrap installs the wrong version. Open a fix PR.”

Target `zombico/mojulo-chatgpt`, inspect bootstrap and CI, reproduce, and verify installation/reuse. Preserve the skills-only architecture unless requested otherwise.

## No executor

“Export the city as GLB.”

Without runtime or portable state, provide a concrete handoff and identify the missing dependency. An export plan is not an exported file.
